# 来源、版本与验证边界

打包日期2026-10-20。G2基础提交 `421a1f64f1840048e980a948c7755b6c171ed66b`，Piper基础提交 `0a4bd001a2957f44703afffdfcfc8ffd90540039`。二者是客户端覆盖层源码快照，不是完整硬件项目。

打包前将G2五个核心脚本SHA256与现场主机逐个比对，全部相同。Piper推理入口和robot.py与现场一致；replay.py、inverse_kinematics.py与旧commit不同，采用打包当天读取的现场版本。完整最终文件身份由MANIFEST.json给出，不把分享包声称为原commit逐字节副本。

Piper现场replay常量已为位置70mm、夹爪70mm，旧说明中的20mm过期。此次未修改现场阈值，仅同步读取。普通推理IK没有旧2mm/1°残差拒绝；独立replay连续IK有额外范围/精度检查。连续命令改正为cycles100000，cycles0不是合法参数。

现场旧 `test_robot.py` 仍断言20mm，已与现场70mm实现不一致；这个过期硬件测试及其旧模型测试辅助没有收入分享包。运行协议和本体映射测试。保留IK测试源码，但因其导入链还需要完整EgoAV项目，仅在接收方完整项目中运行，不作为本次独立测试通过项。没有修改原测试文件来伪造生产验收。

包内共享client、wire和mapping保持源码内容。两份tunnel模块仅将未显式传配置时的历史机器名回退文件改名为 `inference_remote.json`，并移除错误提示中的内部机器名；模型CLI仍明确传各自模型配置，传输逻辑未改。补充README、分享文档、便携启动/校验工具，更新Piper README中的阈值和循环参数。所有真实端点换成配置示例，不包含Git对象及其历史内容。

六模型server完整实现、训练checkpoint、归一化/文本cache、硬件SDK和驱动均由接收方单独取得。可运行的wire codec和mapping已包含；通信本身无需Torch/GPU。

包内测试使用本机TCP回环mock服务，不连接真实server或硬件。通过只能证明字段关联、形状/mask、映射和测试覆盖的IK行为；不证明模型质量、实时性、机器人运动或任务成功。新接收方应在自己的完整环境复验。
